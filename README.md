# Instagram Follower Remover (Chrome Extension)

Instagram-ийн **дагагчдыг (followers)** аюулгүй, хурд хязгаартайгаар бөөнөөр
устгах Chrome өргөтгөл. Профайл дээрх "Followers" цонхыг нээгээд мөр бүрийн
**Remove** товч болон гарч ирэх баталгаажуулах цонхны товчийг автоматаар дардаг.

## Онцлог

- 🧭 Instagram дээр хөвөгч удирдлагын самбар (floating panel)
- 🔢 Хэдэн дагагч устгахаа тохируулах (0 = бүгд)
- ⏱️ Дараалал бүрийн хооронд санамсаргүй хүлээлт → Instagram-д хориглогдохоос сэргийлнэ
- ▶️ / ⏹️ Хэдийд ч эхлүүлэх, зогсоох
- 🈶 Олон хэлний товчны текстийг таних (English, Монгол, Русский, гэх мэт)

## Суулгах (Developer mode)

1. Энэ хавтсыг компьютер дээрээ татаж авах / clone хийх.
2. Chrome дээр `chrome://extensions` руу орох.
3. Баруун дээд булан дахь **Developer mode**-г асаах.
4. **Load unpacked** дараад энэ хавтсыг сонгох.

## Ашиглах

1. `https://www.instagram.com` руу орж нэвтрэх.
2. Өөрийн **профайл** руу орох.
3. **"Followers"** дарж дагагчдын жагсаалтын цонхыг нээх.
4. Баруун дээд буланд гарч ирэх **Follower Remover** самбар дээр:
   - Хэдэн дагагч устгахаа болон хүлээлтийг тохируулах.
   - **Эхлэх** дарах.
5. Устгах явцыг самбар дээр харна. **Зогсоох** дарж хэдийд ч зогсооно.

> Өргөтгөлийн icon дээр дарж popup цонхноос ч мөн адил удирдаж болно.

## ⚠️ Анхааруулга

- Энэ бол автоматжуулалтын туслах хэрэгсэл. Хэт хурдан ажиллуулбал Instagram
  таны хаягийг **түр хааж (action block)** болзошгүй. Хүлээлтийг өндөр (5+ сек)
  байлгахыг зөвлөж байна.
- Instagram-ийн вэб бүтэц өөрчлөгдөхөд товч таних логик шинэчлэх шаардлагатай
  болж магадгүй.
- Энэ хэрэгслийг зөвхөн **өөрийн** хаягтаа, өөрийн хариуцлагаар ашиглана уу.
  Instagram-ийн үйлчилгээний нөхцөлийг зөрчихгүй байхад анхаараарай.

## Файлын бүтэц
